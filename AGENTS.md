# Agent instructions

For all coding agents (Claude Code, Codex, Copilot and others).

1. Read [`CLAUDE.md`](CLAUDE.md) first. It has the non-negotiable rules and the commands. Follow it.
2. For a task, read the matching guide under `.claude/kit/plugins/gc-web/skills/`. Each `SKILL.md` is plain markdown.
   [`gc-web:website`](.claude/kit/plugins/gc-web/skills/website/SKILL.md) is the map. It says which guide covers which job, the
   order of work and the definition of done. Shared guides live in the app repo at
   `../GetChartered/.claude/kit/plugins/gc/skills/`.
3. The reviewer checklists are in `.claude/kit/plugins/gc-web/agents/`.

Keep the rules in one place. Change `CLAUDE.md` or the skill, not this file.
